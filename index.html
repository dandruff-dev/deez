⏱ Timeline (5 Hours) 

T+0:00  All clone repo, create branches, open Trae AI
T+0:15  Each pastes their Session 1 prompt into Trae AI → let it generate
T+1:30  Review Trae output, make minor tweaks, commit + push branch
T+2:00  Member C opens PR first (infra/API needed by others)  ← MERGE ORDER
T+2:15  Member A opens PR (crypto — no UI deps)
T+2:30  Member B opens PR last (UI depends on crypto + API being ready)
T+3:00  All PRs merged to main — app is functional
T+3:30  Each member pastes their Session 2 (polish) prompt in Trae AI
T+4:30  Commit + push polish commits directly to main
T+5:00  Final push — done

Step-by-Step Git Commands

Everyone runs (at T+0:00): 

git clone https://github.com/hawkeye-exe/burner-drop
cd burner-drop

# Member A:
git checkout -b feat/crypto

# Member B:
git checkout -b feat/ui

# Member C:
git checkout -b feat/infra

After Trae AI generates your code: 

# Stage ONLY your files (see table above — do NOT touch others' files)
git add <your files>
git commit -m "feat: <short description of what you built>"
git push origin feat/<your-branch>

Then open a Pull Request on GitHub from your branch → main.

After all PRs are merged (polish commits go straight to main): 

git checkout main
git pull origin main
# Trae AI Session 2 → generate your polish feature
git add <your files>
git commit -m "feat: <polish description>"
git push origin main
Note

If push is rejected: git pull --rebase origin main then push again.
